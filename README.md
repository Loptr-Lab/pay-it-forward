# PLAY IT FORWARD

An interactive, accessible music-fan adventure platform. **NOT A TOY is the proposed pilot test** for the PLAY IT FORWARD tour-companion/adventure format. The pilot is a concept only: artist participation, tour dates, venues, and permissions are not confirmed.

## Local development

- Node.js 20.9+
- `npm install`
- `npm run dev`

## Project principles

- Accessible, keyboard-first, screen-reader-friendly experiences
- Self-paced participation; no timers, pressure, or required purchases
- Remote participation and creative alternatives
- Privacy-conscious: no accounts or analytics in the initial MVP
- Official links only for music and tour information
- Preserve partner/artist permission boundaries

## Pilot test: NOT A TOY

The first proposed adventure pack tests the concept with a NOT A TOY tour companion: optional pre-show listening/discovery, city exploration prompts, show-day accessibility-aware choices, and post-show reflection/share prompts. No tour itinerary or official artist participation is represented.

## MVP

Landing page, adventure selector, sample city quest, music discovery prompts, and PLAY IT FORWARD event page.
